# AI4I 정비 Agent용 가상 매뉴얼 v0.1

> **주의:** 이 문서는 캡스톤 프로토타입을 위한 **합성/교육용 매뉴얼**입니다. 실제 설비 정비 절차가 아닙니다. 실제 현장에서는 제조사 매뉴얼과 안전 절차가 우선합니다.

## M-1. 공통 안전 및 판단 원칙
1. Agent는 고장 유형을 확정하지 않고 **후보**로 제시한다.
2. 모델 확률과 SHAP 값은 정비 판단의 참고자료이며, 실제 원인을 의미하지 않는다.
3. 근거가 부족하거나 상충하면 `근거 부족 → 담당자 검토 요청`으로 종료한다.
4. 실제 조치 전에는 담당자가 센서값, 장비 상태, 작업 가능 여부를 확인한다.
5. 모든 제안에는 관련 매뉴얼 절과 유사 이력 ID를 함께 표시한다.

## M-2. TWF — Tool Wear Failure
**증상 후보:** 공구 마모 증가, 공구 수명 말기 패턴.

**우선 점검**
1. Tool wear 값을 확인한다.
2. 공구 끝단의 마모/손상을 육안 점검한다.
3. 최근 공구 교체 이력을 확인한다.

**조치 초안**
- 공구 상태가 기준을 벗어난 경우 교체 후보로 등록한다.
- 교체 후 시험 가동하고 센서값이 정상 범위로 복귀하는지 확인한다.

## M-3. HDF — Heat Dissipation Failure
**증상 후보:** 열 방출 성능 저하, 공정 온도와 공기 온도 차 감소.

**우선 점검**
1. Air temperature와 Process temperature 차이를 확인한다.
2. 냉각 계통의 상태를 확인한다.
3. 회전 속도가 비정상적으로 낮은지 확인한다.

**조치 초안**
- 냉각 계통 이상 여부를 우선 점검한다.
- 냉각 상태 정상화 후 온도 추이를 재확인한다.

## M-4. PWF — Power Failure
**증상 후보:** 회전 속도와 토크 조합으로 나타나는 동력 조건 이상.

**우선 점검**
1. Rotational speed와 Torque 조합을 확인한다.
2. 구동부 부하 및 동력 전달 상태를 확인한다.
3. 급격한 속도 상승/저하 또는 토크 이상 여부를 확인한다.

**조치 초안**
- 구동부 과소/과대 부하 원인을 확인한다.
- 결합부, 구동 전달부 상태를 점검한다.
- 이상 원인이 제거된 후 시험 가동한다.

## M-5. OSF — Overstrain Failure
**증상 후보:** 높은 토크와 누적 공구 마모가 함께 나타나는 과부하 조건.

**우선 점검**
1. Torque와 Tool wear 조합을 확인한다.
2. 가공 부하가 과도한지 확인한다.
3. 공구, 고정부, 소재 체결 상태를 확인한다.

**조치 초안**
- 과부하 원인을 제거한다.
- 공구 또는 고정부 이상이 있으면 교체/조정 후보로 등록한다.
- 부하 정상화 후 재가동한다.

## M-6. RNF — Random Failure
**증상 후보:** 다른 고장 유형의 명확한 규칙으로 설명되지 않는 이상.

**우선 점검**
1. 최근 알람 및 이벤트 로그를 확인한다.
2. 센서 데이터의 일시적 이상/누락 여부를 확인한다.
3. TWF/HDF/PWF/OSF 근거가 충분한지 재검토한다.

**조치 초안**
- 동일 이상이 재현되는지 확인한다.
- 명확한 근거가 없으면 고장을 임의로 확정하지 않는다.
- `근거 부족`으로 표시하고 담당자 또는 숙련자에게 이관한다.

## M-7. Agent 출력 형식
Agent는 아래 순서를 유지한다.

- 위험도
- 고장 유형 후보(최대 3개)
- 각 후보의 근거
- 검색된 유사 정비 이력
- 다음 점검 1개
- 권장 조치 초안
- 근거 부족 여부
- 담당자 검토 필요 여부

예시:

```text
위험도: HIGH
고장 유형 후보 1: PWF
근거: 높은 회전 속도와 낮은 토크가 모델 판단에 크게 기여
유사 이력: H-0013, H-0014, H-0015
다음 점검: 구동부 부하 및 동력 전달 상태 확인
권장 조치: 이상 부품/결합 상태 점검 후 시험 가동
주의: AI 판단은 확정 진단이 아니며 담당자 확인 필요
```
